# **ClauseCheck**

**ClauseCheck** — a small API that screens one contract clause for risky wording by calling an LLM (Claude, through the OpenAI SDK), and returns a risk level plus the exact phrases that worry it. It is a triage tool for a legal-ops team: a lawyer still decides. Deliberately unrelated to any other example in this guide: no shared code, no shared domain, nothing to cross-reference. If you only ever read this one section, you have everything you need to build it.
